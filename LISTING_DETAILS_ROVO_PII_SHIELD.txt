### Stop Enterprise AI Data Leaks at the Network Edge

Deploying autonomous AI agents (like Atlassian Rovo, Cursor AI, or Claude Desktop) across corporate Jira workspaces introduces severe compliance and security risks. Raw prompts can inadvertently leak customer credit cards, employee Social Security Numbers, internal IP addresses, and private API keys.

**SEOSiri Rovo MCP & PII Shield** acts as a Zero-Trust edge proxy and protocol-level AI Firewall deployed across Cloudflare global edge nodes (`rovomcp.seosiri.com`), sanitizing all data streams in real time before external model processing.

---

### 🛡️ Enterprise Security & Data Governance Engines

1. **Real-Time Data Masking:**
   - Edge-level regex scrubbing for Social Security Numbers (SSN), credit cards (PCI-DSS Luhn token masking), emails, and phone numbers.
   - Zero-latency execution on Cloudflare V8 isolates without database read/write bottlenecks.

2. **Healthcare & Financial Compliance Verticals:**
   - **Healthcare (HIPAA PHI):** Automatically detects and redacts Medical Record Numbers (MRN), DEA registrations, and patient identifiers.
   - **Finance (PCI-DSS / Banking):** Masks account numbers and credit card sequences.
   - **Software & Cloud:** Redacts internal corporate VLANs, RFC 1918 private IPs, and RSA private keys.

3. **AI Prompt Firewall:**
   - Intercepts prompt injection exploits, system prompt override attempts, and malicious tool-call parameter tampering.

4. **Multi-Client & Rovo Bridge:**
   - Exposes a unified, authenticated JSON-RPC 2.0 interface serving Cursor, VS Code, Claude Desktop, and Atlassian Rovo Agents.

5. **Zero-Cost Storage Economics:**
   - Persists tenant policy settings inside Atlassian's native `@forge/bridge` storage vault, ensuring customer data never sits on third-party tracking databases.
